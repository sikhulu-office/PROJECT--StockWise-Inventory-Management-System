# PROJECT--StockWise-Inventory-Management-System
This is a Python-based inventory management system for a small store that helps manage product stock, check inventory levels, track restocking and add new products. StockWise includes a simple menu-driven interface. The inventory data and changes are stored on a JSON file, allowing the data to persist even when the application is closed.

## ✨ Features

- View Inventory: Displays all the products, their price, their quantity, individual stock values and the total stock value.
- Product search: Search for products by name.
- Add New Search: Add products with price and quantity validations.
- Input validation: Rejects invalid numerical inputs and prevents negative prices and quantities.
- Cancel Product Entry: Type CANCEL to abort a new product entry into the invemtory.
- Duplication Protection: Prevent same products that exist already in the inventory from being added.
- Restock: Restock product units onto existing quantity in the inventory.
- Low-stock Alerts: Identifies which product is low on stock and how many units are still remaining.
- Data Persistence: Save and load inventory data using the JSON file.

## 🛠️ Technologies Used

Python - Application development and logic.
JSON - Inventory data storage and persistence.
